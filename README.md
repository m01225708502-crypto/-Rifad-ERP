# رِفاد ERP

مشروع تأسيسي لنظام محاسبة ومخازن عربي يعمل على Windows 10/11.

## الحالة الحالية
هذه **نسخة بداية تقنية** وليست إصدار ERP مكتملًا أو جاهزًا للاستخدام التجاري. تتضمن:
- تطبيق Windows Forms بواجهة عربية واتجاه RTL.
- قاعدة SQLite تُنشأ تلقائيًا عند أول تشغيل.
- هيكل أولي للشاشة الرئيسية.
- GitHub Actions للبناء على Windows دون الحاجة إلى تثبيت .NET SDK على جهازك.

## المتطلبات
- Windows 10 أو Windows 11 (64-bit).
- .NET 10 Desktop Runtime لتشغيل التطبيق بعد نشره.

## البناء السحابي
عند رفع المستودع إلى GitHub، شغّل workflow باسم **Build Rifad ERP** من تبويب Actions أو ادفع تحديثًا إلى فرع `main`.
ينتج ملف ZIP منشورًا كـ Artifact من عملية البناء.

## وحدات يجب استكمالها واختبارها
دفتر الأستاذ والقيود، دليل الحسابات، الخزينة، العملاء والموردون، المبيعات والمشتريات، الأصناف والمخازن، التقارير، المستخدمون والصلاحيات، النسخ الاحتياطي والاستعادة.
